# procurementAI - Frontend

This is the Next.js frontend for ProcureAI (Procurement & Supply Chain Risk Intelligence).

## Getting Started

First, install dependencies:

```bash
npm install --legacy-peer-deps
```

Then run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Available Routes:
- `/` - Real-time Dashboard with KPIs, Inventory Forecasts & Alerts
- `/chat` - Procurement Assistant Chat
- `/po-queue` - Purchase Order Queue with Agent Explanations & Approval Flow
- `/simulator` - What-If Risk Simulator
